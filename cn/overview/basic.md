# 基本データ

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 中華人民共和国（1949年10月1日建国） |
| 首都 | 北京 |
| 面積 | 約960万km²（世界第3〜4位） |
| 人口 | 約14億1,000万人（2022年から減少に転じた） |
| 公用語 | 標準中国語（普通話）。ほかにチベット語、ウイグル語などがあるが、教育現場での普通話化が進められている |
| 通貨 | 人民元（CNY） |
| 国家主席 | 習近平（2013〜。2018年の憲法改正で任期制限を撤廃） |
| 体制 | 中国共産党の一党支配。憲法に党の指導が明記されている |
| 行政区画 | 22省、5自治区、4直轄市、2特別行政区（香港・マカオ）。台湾を「23番目の省」と主張しているが、台湾を統治したことは一度もない |
