# 経緯（年表）

> 本ページは、公開されている二次情報（百科事典類、研究論文、報道）を基にした整理です。**協定の条文や人数・時期の細部は、外務省の外交史料などの一次資料で確認してください**。

| 年 | 出来事 |
| --- | --- |
| 1962 | **LT貿易**（日中長期総合貿易）が始まる。国交のない状態での、半官半民の貿易の枠組み |
| 1964年4月19日 | LT貿易を担当していた**高碕達之助事務所**と**廖承志事務所**が、「**日中双方の新聞記者交換に関するメモ**」を取り交わす。政府間の署名ではなく、**民間（事務所）レベルの取り決め** |
| 1964年9月 | 日本の報道機関（9社・局とされる）が、**北京に記者を常駐**させる。中国側も記者を東京に派遣 |
| 1960年代後半 | 中国は、報道内容を**政治三原則**に照らして確認。抵触すると判断すれば、抗議や記者の追放を行ったとされる |
| 1967 | **産経新聞**の北京支局長が追放されたとされる。同社は中国側の要求（台湾支局の閉鎖）を拒否した。以後、**1998年まで北京に支局を置けなかった**とする資料がある |
| 1968年3月 | LT貿易が**覚書貿易（MT貿易）**に移行。記者の枠が縮小され（5人とする資料がある）、**政治三原則が「遵守すべき原則」として明記**された |
| 1972 | **日中国交正常化**。民間の枠組みから、**政府間の関係**に移行 |
| 1970年代以降 | 国交正常化後、**政府間の記者交換に関する交換公文**が結ばれ、記者の常駐が制度化された |
