# 主な事件

以下は、報道・捜査で明らかになった主な事例です。捜査・裁判が継続中の案件は、**有罪が確定したものではありません**。

| 時期 | 事例 |
| --- | --- |
| 2021年10月 | **パンドラ文書**で、ゼレンスキー大統領とその側近が関わるオフショア企業の存在が報じられた（違法性は認定されていない） |
| 2023年1月 | 国防省の**食料調達**で価格が水増しされていたと報じられ、次官が辞任。同月、大統領府の副長官が高級車の使用問題で辞任、インフラ次官が発電機の調達に絡む収賄容疑で拘束された |
| 2023年8月 | ゼレンスキー大統領が、**地方の徴兵事務所の所長を全員解任**（徴兵をめぐる賄賂が理由） |
| 2023年9月 | レズニコフ国防相が交代（腐敗問題との関連が指摘された） |
| 2023年9月 | 有力オリガルヒの**コロモイスキー**が詐欺容疑で拘束 |
| 2025年7月 | NABU・SAPの独立性を弱める法律をめぐり、抗議が起きて撤回 |
| 2025年11月 | NABU・SAPが、国営原子力企業**エネルゴアトム**をめぐる約1億ドル規模のキックバックの疑惑を公表（「ミダス作戦」）。ゼレンスキー氏の元ビジネスパートナーが関与したと報じられ、司法相・エネルギー相が辞任、その後**大統領府長官のイェルマーク氏が辞任** |

- 2025年11月以降の捜査・裁判の進展は、各報道で確認してください。
