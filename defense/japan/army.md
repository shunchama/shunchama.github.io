# 陸上自衛隊

> 数値は防衛白書、SIPRI、IISS『ミリタリー・バランス』、米国防総省の中国軍事力報告書などの公表資料に基づく**概数・推計**です（2024〜25年ごろ）。最新値や、実際の保有数・稼働状況とは異なる場合があります。

## 主な装備

| 区分 | 装備 | 概要 |
| --- | --- | --- |
| 戦車 | **10式戦車**、90式戦車 | 10式は国産の第4世代戦車。74式は退役中。戦車の総数は約300〜400両規模で、減少傾向 |
| 装輪戦闘車 | **16式機動戦闘車** | 105mm砲を搭載した、機動力の高い装輪車両 |
| 火砲 | 99式自走155mmりゅう弾砲、FH70 | 老朽化した火砲の更新が課題 |
| 対艦ミサイル | **12式地対艦誘導弾** | 射程は約200km。**能力向上型**（射程約1,000km級）の配備が2025〜26年度から順次始まる |
| 防空 | 03式中距離地対空誘導弾（改）、11式短距離地対空誘導弾 | 中SAMは高い迎撃性能を持つ |
| 水陸両用 | **AAV7**（水陸機動団） | 2018年に新編した水陸機動団が運用 |
| 航空 | CH-47JA、UH-60JA、**V-22オスプレイ**（17機） | 攻撃ヘリは退役が進み、無人機への転換を計画 |

## 部隊の特徴

- **水陸機動団**（長崎県佐世保）：離島の奪還を担う日本版の海兵隊的な部隊。
- 南西諸島には、**地対艦ミサイル部隊、地対空ミサイル部隊、電子戦部隊**などを配備している。
