# ミサイル・反撃能力

> 数値は防衛白書、SIPRI、IISS『ミリタリー・バランス』、米国防総省の中国軍事力報告書などの公表資料に基づく**概数・推計**です（2024〜25年ごろ）。最新値や、実際の保有数・稼働状況とは異なる場合があります。

## 反撃能力（スタンド・オフ防衛能力）

2022年の3文書で、**相手の領域内の軍事目標を攻撃できる能力**の保有を決定した。

| 装備 | 概要 |
| --- | --- |
| **12式地対艦誘導弾（能力向上型）** | 射程約1,000km級。地上発射、艦艇発射、航空機発射の3種類を開発 |
| **トマホーク**（米国製） | 約400発を取得する計画。イージス艦に搭載し、2025年度から順次配備 |
| **島嶼防衛用高速滑空弾（HVGP）** | 早期装備型が2026年度ごろから配備。離島防衛用 |
| **極超音速誘導弾（HCM）** | 開発中 |
| **JSM／JASSM-ER** | F-35やF-15に搭載する長距離空対地ミサイル |

## ミサイル防衛

- **イージス艦（SM-3、SM-6）** と **ペトリオット（PAC-3）** の二段構え。
- **イージス・システム搭載艦**（2隻）：陸上配備のイージス・アショア計画が中止（2020年）された後の代替策。2027〜28年度の就役を目指す。
- 極超音速兵器への対応は、**迎撃が難しい**ことが課題。

## 核

- 日本は核兵器を保有していない。**米国の拡大抑止**（核の傘）に依存している。
