# 海軍

> 数値は防衛白書、SIPRI、IISS『ミリタリー・バランス』、米国防総省の中国軍事力報告書などの公表資料に基づく**概数・推計**です（2024〜25年ごろ）。最新値や、実際の保有数・稼働状況とは異なる場合があります。

## 規模

- **艦艇数は約370隻**で、**数では世界最大**（米国防総省の推計）。2030年には435隻に達するとされる。

## 空母

| 艦名 | 備考 |
| --- | --- |
| **遼寧**（001型） | 旧ソ連のワリヤーグを改修。2012年就役 |
| **山東**（002型） | 国産の初の空母。2019年就役 |
| **福建**（003型） | **電磁カタパルト**を搭載した中国初の艦。2025年11月に就役 |

## 水上艦・揚陸艦

- **055型駆逐艦**（約8隻）：1万トン級のイージス艦に相当する大型艦。
- **052D型駆逐艦**（約25隻以上）、054A型フリゲート（約30隻）。
- **075型強襲揚陸艦**（3隻）、**076型**（試験中）。台湾への上陸作戦も意識されている。

## 潜水艦

- 約**60隻**。
  - **094型**（弾道ミサイル原潜）6隻。
  - **093型**（攻撃型原潜）6隻前後。
  - **039型（元級）**などの通常動力潜水艦が約45〜50隻。
- 次世代の**096型**原潜の開発も報じられている。
