# 空軍

> 数値は防衛白書、SIPRI、IISS『ミリタリー・バランス』、米国防総省の中国軍事力報告書などの公表資料に基づく**概数・推計**です（2024〜25年ごろ）。最新値や、実際の保有数・稼働状況とは異なる場合があります。

## 戦闘機・爆撃機

| 機種 | 概要 |
| --- | --- |
| **J-20** | 第5世代ステルス戦闘機。**250〜300機**規模と推計（年間数十機を生産） |
| **J-35／FC-31** | 第5世代の中型ステルス機。艦載型も開発。2025年の軍事パレードでも登場 |
| **J-16** | 多用途戦闘機。数が多い |
| **J-10C** | 国産の軽量多用途戦闘機 |
| **J-15** | 艦載機（空母用） |
| **Su-35**（ロシア製） | 24機を導入 |
| **H-6K／N** | 爆撃機。巡航ミサイルの搭載が可能。長距離化が進む |
| **H-20** | 開発中のステルス爆撃機とされる |

- 2024年12月、**第6世代機とみられる試験機**が確認されたと報じられた（J-36など）。

## その他

- **Y-20**（大型輸送機）、**KJ-500／KJ-2000**（早期警戒機）、空中給油機。
- 作戦機の総数は**3,000機超**（推計）。日本の戦闘機の**数倍**の規模。
