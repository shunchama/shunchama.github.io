# 陸軍

> 数値は防衛白書、SIPRI、IISS『ミリタリー・バランス』、米国防総省の中国軍事力報告書などの公表資料に基づく**概数・推計**です（2024〜25年ごろ）。最新値や、実際の保有数・稼働状況とは異なる場合があります。

| 区分 | 装備 | 概要 |
| --- | --- | --- |
| 主力戦車 | **99A式**、96式系、**15式軽戦車** | 数は多いが、一部は旧式 |
| 歩兵戦闘車 | ZBD-04A、ZBD-05（水陸両用） | |
| 火砲 | PLZ-05（155mm自走砲）、PHL-16（多連装ロケット） | 長射程ロケットの整備が進む |
| 防空 | HQ-16、HQ-17、HQ-22、**S-400**（ロシア製） | |
| ヘリ | **Z-10**（攻撃）、**Z-20**（汎用）、Z-8 | |

- 2017年の再編で、師団から**合成旅団**に移行した。
- **水陸両用部隊**と**空挺部隊**の整備が、台湾有事を意識して進められている。
