# ロケット軍と核戦力

> 数値は防衛白書、SIPRI、IISS『ミリタリー・バランス』、米国防総省の中国軍事力報告書などの公表資料に基づく**概数・推計**です（2024〜25年ごろ）。最新値や、実際の保有数・稼働状況とは異なる場合があります。

## ロケット軍

- 2015年に、第二砲兵部隊から**ロケット軍**に格上げされた。
- 通常弾頭と核弾頭の両方のミサイルを運用する。

| ミサイル | 射程（概数） | 概要 |
| --- | --- | --- |
| **DF-21D** | 約1,500km | 対艦弾道ミサイル（「空母キラー」と呼ばれる） |
| **DF-26** | 約4,000km | 中距離弾道ミサイル（「グアムキラー」）。核・通常の両用 |
| **DF-17** | 約2,000km | **極超音速滑空体**を搭載 |
| **DF-27** | 5,000km超 | 中・長距離 |
| **DF-31AG／DF-41** | 約1万2,000〜1万5,000km | 大陸間弾道ミサイル（ICBM） |
| **DF-5B／5C** | 1万km超 | 大型ICBM |

- 日本全土は、**中距離・準中距離ミサイルの射程**に入っている（日本向けに数百発規模と推計される）。
- 2025年9月の軍事パレードでは、ICBM、極超音速兵器、無人機、レーザー兵器などが公開された。

## 核戦力

- 核弾頭は**約600発**（2024〜25年の推計）。**2030年には1,000発超**に増えると、米国防総省は見積もっている。
- **ICBM用のサイロを約300基**建設中と指摘される（2021年に発覚）。
- 公式には「**先制不使用**」を宣言している。ただし透明性は低く、軍備管理協議にも消極的。
- **海・空・陸の核の三本柱**（094型原潜、H-6N、ICBM）の整備を進めている。
