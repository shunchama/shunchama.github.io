# 基本データ

| 項目 | 内容 |
| --- | --- |
| 呼称 | 台湾（正式な国号は**中華民国**） |
| 首都 | 台北（中華民国政府の所在地） |
| 面積 | 約3万6,000km²（九州よりやや小さい） |
| 人口 | 約2,300万人 |
| 言語 | 華語（北京語系）、台湾語（閩南語）、客家語、先住民諸語 |
| 政体 | 民主共和制。総統は4年任期・直接選挙。立法院は一院制 |
| 通貨 | 新台湾ドル（TWD） |
| 外交関係 | 十数か国と正式な国交。日本・米国などとは非公式の実質関係 |
| 経済 | 半導体（TSMC）を中心とするハイテク産業。**先端半導体の受託製造で世界の大部分を占める** |

- 先住民族は**16族**が政府に公式認定されている（人口の約2%）。
- 住民の多数は、17〜19世紀に中国大陸南部（福建・広東）から移った人々の子孫（本省人）と、1949年前後に国民党とともに渡った人々とその子孫（外省人）。
- 世論調査では、「自分は台湾人」と考える人が過半数を占める。
