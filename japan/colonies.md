# 植民地・勢力圏

| 地域 | 経緯 | 統治の概要 |
| --- | --- | --- |
| **台湾** | 1895年 下関条約 | 台湾総督府。インフラ整備と同化政策。[台湾の歴史](../taiwan/japan-rule.html)を参照 |
| **南樺太** | 1905年 ポーツマス条約 | 樺太庁。1943年に内地に編入 |
| **関東州** | 1905年 租借 | 関東都督府→関東庁。旅順・大連 |
| **朝鮮** | 1910年 韓国併合 | 朝鮮総督府。近代化と同化政策、**創氏改名**、徴用 |
| **南洋諸島** | 1919年 国際連盟の委任統治 | 南洋庁。パラオ・サイパンなど |
| **満洲国** | 1932年 建国 | 関東軍が実権を握る傀儡国家。「五族協和」を掲げた |
| **東南アジア占領地** | 1941〜45年 | 軍政。「大東亜共栄圏」。インドネシア、ビルマなどでは**日本軍が独立運動を支援した側面と、強制労働・食糧徴発の被害の両方**がある |

- **大東亜会議**（1943年）：日本は、アジアの「独立」を支援する姿勢を示したが、実態は日本の戦争遂行のための資源の確保だった。
- 日本の統治は、欧米の植民地統治に比べて**同化主義が強い**と指摘される。
