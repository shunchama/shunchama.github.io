# 地理

- **ユーラシア大陸の北部**に広がり、西のバルト海・黒海から東の太平洋まで続く。
- **ウラル山脈**がヨーロッパ・ロシア（西）とシベリア（東）の慣習的な境界。人口の約4分の3はウラル以西に住む。
- **シベリア**は国土の約4分の3を占める広大な地域。資源（石油・天然ガス・石炭・金属）の宝庫。
- **シベリア鉄道**（モスクワ〜ウラジオストク、約9,300km）は世界最長級の鉄道。
- **バイカル湖**は世界最深（約1,640m）・最大級の淡水湖。
- 気候は大部分が冷帯・寒帯。ヤクーツク周辺には北半球の寒極とされる地域がある。
- **凍土**が広く分布し、地球温暖化による融解がインフラや温室効果ガスの問題になっている。
- 日本とは北方領土（択捉・国後・色丹・歯舞群島）をめぐる問題を抱え、平和条約は未締結。

### 主な都市

| 都市 | 特徴 |
| --- | --- |
| モスクワ | 首都。クレムリン、赤の広場。政治・経済の中心 |
| サンクトペテルブルク | ピョートル大帝が建設した帝政期の首都。「北のヴェネツィア」 |
| ノヴォシビルスク | シベリア最大の都市。科学都市アカデムゴロドク |
| エカテリンブルク | ウラル地方の中心。ロマノフ家が処刑された地 |
| ウラジオストク | 極東の港湾都市。日本海に面し、「東方を支配せよ」の意 |
| カリーニングラード | 飛び地（ポーランドとリトアニアに挟まれる）。バルト艦隊の拠点 |
