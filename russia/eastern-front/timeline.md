# 年表

| 年月 | 出来事 |
| --- | --- |
| 1941年6月22日 | バルバロッサ作戦開始 |
| 1941年7月 | スモレンスクの戦い |
| 1941年9月 | **レニングラード包囲戦**開始（〜1944年1月、約900日）。キエフ包囲戦で約60万人のソ連軍が捕虜に |
| 1941年9月 | バビ・ヤール（キエフ郊外）で約3万3千人のユダヤ人が殺害される |
| 1941年10〜12月 | **モスクワ攻防戦**。12月5〜6日にソ連軍が反攻、独軍は撃退された |
| 1942年夏 | ドイツ軍が南方で「青作戦」を開始。コーカサスの油田とスターリングラードを目指す |
| 1942年7月 | スターリン「**命令第227号**」（「一歩も退くな」） |
| 1942年8月〜43年2月 | **スターリングラードの戦い**。1942年11月19日に包囲作戦（ウラヌス作戦）が発動。1943年2月2日、独第6軍が降伏 |
| 1943年7月 | **クルスクの戦い**。史上最大級の戦車戦。以後ドイツ軍は攻勢に出られなくなる |
| 1943年11月 | キエフ奪還。テヘラン会談 |
| 1944年1月 | レニングラード解放 |
| 1944年6月 | 連合軍がノルマンディー上陸（第二戦線）。同月22日、**バグラチオン作戦**（ベラルーシ解放）でドイツ中央軍集団が壊滅 |
| 1944年8〜9月 | ルーマニア・ブルガリア・フィンランドが枢軸側から離脱 |
| 1945年1月 | ヴィスワ＝オーデル攻勢。アウシュヴィッツ解放（1月27日） |
| 1945年2月 | ヤルタ会談 |
| 1945年4月16日〜5月2日 | **ベルリンの戦い** |
| 1945年5月8日（モスクワ時間9日） | ドイツ降伏。ロシアでは5月9日が「勝利の日」 |
| 1945年8月8日 | ソ連が対日参戦、満洲・樺太・千島へ侵攻 |
