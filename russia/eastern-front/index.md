# 独ソ戦（1941–45）

1941年6月22日にナチス・ドイツがソ連へ侵攻して始まり、1945年5月のドイツ降伏で終わった戦争。ロシアでは**大祖国戦争**と呼ぶ。第二次世界大戦で最大規模・最大被害の戦線だった。
