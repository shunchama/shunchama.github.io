# 年表

| 年 | 出来事 |
| --- | --- |
| 1905 | 第一次ロシア革命（血の日曜日事件）。ソビエト（評議会）が初めて登場 |
| 1914 | 第一次世界大戦に参戦 |
| 1917 | **二月革命**（ロマノフ朝崩壊）→ **十月革命**（レーニン率いるボリシェヴィキが政権掌握） |
| 1918 | ブレスト＝リトフスク条約で大戦から離脱。内戦・外国干渉（シベリア出兵含む）開始 |
| 1921 | 内戦終結。**ネップ（新経済政策）**導入 |
| 1922 | **ソ連成立** |
| 1924 | レーニン死去。後継争いが始まる |
| 1928 | 第1次五カ年計画開始。農業集団化・急速な工業化 |
| 1932–33 | 大飢饉（ウクライナの**ホロドモール**など） |
| 1936–38 | **大粛清（大テロル）**。数十万〜百万人規模が処刑されたとされる |
| 1939 | 独ソ不可侵条約（秘密議定書で東欧分割）。9月にソ連がポーランド東部へ侵攻 |
| 1941 | 独ソ戦（ソ連側で言う**大祖国戦争**）開始 |
| 1943 | スターリングラードの戦いでドイツ軍が降伏 |
| 1945 | ベルリン陥落、対日参戦（8月）。ヤルタ・ポツダム会談 |
| 1949 | 原爆実験成功、COMECON設立 |
| 1953 | スターリン死去 |
| 1955 | **ワルシャワ条約機構**成立 |
| 1956 | フルシチョフの**スターリン批判**。ハンガリー動乱を武力鎮圧。日ソ共同宣言 |
| 1957 | 人工衛星スプートニク1号 |
| 1961 | ガガーリンが有人宇宙飛行。ベルリンの壁建設 |
| 1962 | **キューバ危機** |
| 1964 | フルシチョフ失脚、ブレジネフ時代へ |
| 1968 | 「プラハの春」を軍事介入で弾圧。ブレジネフ・ドクトリン |
| 1979 | **アフガニスタン侵攻** |
| 1982 | ブレジネフ死去。アンドロポフ、チェルネンコと短命政権が続く |
| 1985 | **ゴルバチョフ**が書記長に就任 |
| 1986 | **チェルノブイリ原発事故**。「ペレストロイカ」「グラスノスチ」が本格化 |
| 1989 | 東欧革命。ベルリンの壁崩壊。ソ連軍がアフガンから撤退完了 |
| 1990 | 共産党の一党独裁を放棄。ゴルバチョフが初代（最初で最後の）大統領に |
| 1991 | 8月クーデター未遂。バルト三国が独立承認。12月、**ベロヴェーシ合意**で独立国家共同体（CIS）創設。**12月25日ゴルバチョフ辞任、26日ソ連消滅** |
