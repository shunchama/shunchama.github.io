# ソ連の歴史

**ソビエト社会主義共和国連邦**（СССР / USSR）は、1922年12月30日に成立し、1991年12月26日に消滅した世界初の社会主義国家。ロシア・ウクライナ・ベラルーシ・ザカフカース（のちに分割）の4共和国で発足し、最終的に15の連邦構成共和国から成った。
