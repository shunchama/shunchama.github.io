# 時代区分と指導者

| 指導者 | 期間 | 特徴 |
| --- | --- | --- |
| **レーニン** | 1917〜24 | 革命と建国、戦時共産主義からネップへ |
| **スターリン** | 1920年代後半〜53 | 独裁体制。工業化・集団化・大粛清・戦勝 |
| **マレンコフ／フルシチョフ** | 1953〜64 | 「雪解け」。スターリン批判、宇宙開発、キューバ危機 |
| **ブレジネフ** | 1964〜82 | 「停滞の時代」。軍拡・デタント・アフガン侵攻 |
| **アンドロポフ／チェルネンコ** | 1982〜85 | 老齢で短命 |
| **ゴルバチョフ** | 1985〜91 | 改革（ペレストロイカ）、冷戦終結、ソ連崩壊 |
